
# Mod Description

Welcome  to Slay Them Deadly Sins!
This is a mod for Slay The Spire 2 mainly focused on adding a bunch of content to Megacrit's Slay The Spire 2. The mod is supposedly vaguely themed around the Seven Deadly Sins - hence the name - and the current plan is to push for seven different ancients all thememed around one of those, but mainly the focus is adding a bunch of content to the game.
